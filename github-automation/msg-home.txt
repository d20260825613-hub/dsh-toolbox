feat(home): 重做为个人开源工具箱主页

原来的首页是 PaperMod 默认的博客列表页：一块文字简介 + 文章条目，没有头像、没有
项目卡片、没有图片，文档感重。现在改成作品集式主页 —— 访客一眼看到"这是谁、
做了什么工具、怎么联系"。

首屏：圆形头像 + 身份标签「独立工具开发者」+ 站名「堆栈手记」+ 中文简介 +
联系方式（邮箱可点击发信 / 所在地 / 维护状态）+ 四个入口按钮。

项目展示：netpeek / dropjar / tabkit / spacehog 各一张卡片，含名称、一句话简介、
状态标签、元信息、分类标签与 GitHub 入口；网格布局，hover 上浮，窄屏自动单列。

视觉：深色科技感（石墨黑 + 青蓝强调色）、玻璃拟态卡片、内联 SVG 图标（不产生额外
请求，stroke 用 currentColor 故自动跟随配色）、背景图 1600×900 + 窄屏 900×507
两套，遮罩强度可配。

实现方式刻意保持不动主题：
- 首页放在 layouts/list.html，只覆盖 main 块 —— PaperMod 的首页渲染就在它的
  list.html 里（判断 .IsHome），项目 layouts/ 优先于主题，因此文章页、标签页、
  搜索、归档、404 全部不受影响；baseof/header/footer 仍由主题提供，导航与站内
  搜索的功能没有被重写。
- 样式放 assets/css/extended/home.css —— PaperMod 会自动把该目录合并进主样式表，
  所以 themes/ 一个字节都不用改，主题升级也不会冲突。
- 内容全部在 data/home.yaml：改文字、加项目、换联系方式只改这个文件。
- 头像有回退：static/images/avatar.webp 存在就用它，否则用占位 SVG，无需改代码。
- 背景图的存在性在模板里检查，没配就整层跳过（不会产生 404 请求）。

首页恒定深色，不跟随主题切换 —— 这是刻意的。跟随主题有两个具体问题：亮色主题下
夜景背景图与白底相撞，淡出位置会留一条硬边；深色遮罩配浅色表面会变成灰蒙蒙的
中间调。想改回跟随主题，只需删掉 .home 顶部那段变量覆盖。README 第四节记了原因。

期间踩到并已规避的坑（都写进了代码注释与 README 排错表）：
- 背景图最初用 position:fixed，滚到卡片时仍透出来；为挡住它给容器加实色底，
  又在亮色主题下变成一块白色面板。改成 absolute + 固定高度，只包住首屏。
- .main 的主题宽度上限是 720px，而首页信息量更大；放宽后必须配 overflow-x: clip，
  否则通栏背景会让窄屏出现横向滚动。
- **修改 assets/ 下的 CSS 有时不会让 Hugo 资源缓存失效**，表现为"改了样式但页面
  没变"，而 --gc 与删 public/、resources/ 都无效，必须清 %LOCALAPPDATA%\hugo_cache。
  这一条让我白排查了两轮，已写进 README。
- 无头 Edge/Chrome 不接受小于约 500px 的窗口，直接用 --window-size=390 截图会得到
  被裁过的假象，看起来像"移动端横向溢出"。新增 scripts/cdp-viewport.js 用 CDP 的
  Emulation.setDeviceMetricsOverride 强制真实视口，并打印关键元素的实测宽度与
  计算颜色。实测 390px 下 scrollWidth == 视口宽度，无溢出。

新增 scripts/verify-home.js：首页验收（结构、视觉元素、四张卡片、搜索索引、
其它页面未被破坏），当前全部通过。同一份断言也能防止以后改首页时误伤搜索与评论。
