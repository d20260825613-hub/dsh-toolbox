## 这个博客是什么

这是我用静态站点生成器搭起来的个人博客：写完 Markdown 执行一次部署脚本，
静态页面就会被上传到 Cloudflare 的全球节点，公网 HTTPS 直接可访问，
**不需要买域名，也不需要服务器**。

## 技术栈

| 组成 | 选择 | 为什么 |
| --- | --- | --- |
| 生成器 | Hugo | 单文件二进制、构建极快、零运行时依赖 |
| 主题 | PaperMod | 轻量、自带目录 / 归档 / 标签 / 搜索，有中文界面 |
| 托管 | Cloudflare Pages | 免费额度足够个人博客，自动 HTTPS + 免费二级域名 |
| 部署 | Wrangler CLI | 本地一条命令上传，不依赖任何 CI 服务 |

## 我打算写些什么

- **技术笔记**：踩过的坑、验证过的方案
- **读书笔记**：读到的好东西
- **生活记录**：一些想法和片段

## 怎么找到想看的文章

顶部导航有四个入口：

1. **文章** —— 全部分页列表
2. **归档** —— 按年月倒序排列
3. **标签** —— 按主题聚合
4. **搜索** —— 站内关键词搜索

> 提示：在任意页面按 <kbd>/</kbd> 键也能直接跳到搜索框。
